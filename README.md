# Strategio (original prototype)

**This is the early prototype of Strategio, kept for history. Active development has moved.**

> **Looking for the game?** Go to **[Manatros/-strategio](https://github.com/Manatros/-strategio)**.
> That's the current Strategio: a real-time hex-grid strategy game in the browser with six
> asymmetric races, bots, diplomacy and a full server/client rewrite.

## What's in here

The very first attempt at Strategio ("best strategy browser game EU-West"): a small Node.js
**Express** app with EJS views, a noise-generated tile map, a login page and a highscore page.

| Branch | Contents |
|---|---|
| `main` | Cleaned up; only this README and a few leftover config files remain. |
| [`Manatros-patch-1`](https://github.com/Manatros/Strategio/tree/Manatros-patch-1) | The original Express app (`app.js`, `routes/`, `views/`, `public/js/` map, tile and player scripts). |
| `dev` | Latest state of this repository. Since the project moved, it only receives occasional cleanup. |

[Manatros/-strategio](https://github.com/Manatros/-strategio) instead.
